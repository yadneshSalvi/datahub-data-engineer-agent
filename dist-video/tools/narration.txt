Companies run on data pipelines. Raw tables feed cleaned tables, which feed the dashboards executives read. DataHub is an open source catalog that maps every table, every column, and every dependency between them.

DataHub also stores what you need when something breaks: schemas, owners, usage, incidents, assertions. Six read tools reach it through DataHub's MCP server; seventeen more, on the Python SDK, run the deeper checks and write back.

This is the agent's control panel. On the right, the catalog snapshot from DataHub: twenty three assets in a ride hailing data warehouse, all healthy.

Now we stop the ingestion job. An assertion is an automated data quality check DataHub runs against a table. Downstream checks start failing, and the inbox on the left fills up.

The top row: agg daily rides has collapsed to four rows, where its check expected at least twenty five. One click, and the agent takes the page.

Its first move is memory. It searches DataHub for post mortems it wrote before, indexed as a searchable structured property. Nothing. So it climbs the lineage, the map of which table feeds which, one hop at a time.

At every table it asks what a human would, all through DataHub. Is the assertion passing. Is the data fresh. Did the row count collapse. Did the schema change.

Staging trips is broken, but its parent is worse, so it keeps climbing and stops at trips raw. Twenty six hours stale against a six hour limit. Nothing feeds it, and it confirms that rather than assuming.

Then it works downstream: fifteen assets, ranked by usage from DataHub. Then it acts inside DataHub, filing an incident, tagging the root cause down to the column, notifying the owners, and writing a post mortem back in.

Now a different table breaks, three hops away. This time the search hits. It finds its own post mortem, then uses DataHub's column level lineage to check the path from the same source, and goes straight to the answer.

Same root cause. On this pair of runs: twenty four percent fewer tool calls, fourteen percent less time, the same three hops. Written back into DataHub, where the next engineer finds it.
